Thay đổi so với plan ban đầu

  • Importer ưu tiên repo path match. Project slug chỉ được dùng khi slug đủ riêng biệt, vì các slug quá chung như repo dễ import nhầm session từ lịch sử Codex thật trên máy.
  • Khi có AGENT_BOOTSTRAP_CODEX_SESSIONS_ROOT, importer chỉ scan root explicit đó. Điều này giữ test và smoke run cô lập, đồng thời giảm rủi ro scan nhầm common home roots khi user đã chỉ định nguồn session rõ ràng.
  • Recency boost chỉ được cộng khi đã có lexical/concept/title/kind signal thật. Nếu không, query rác vẫn có thể trả memory mới nhất, gây hallucination nhẹ.
  • Normal output của recall vẫn gọn; score breakdown tồn tại trong result object/runtime internals nhưng không phơi quá nhiều ra CLI output.

Tradeoff AI phải cân nhắc

  • Semantic recall không dùng embedding nên nhẹ, offline, dễ audit, nhưng chỉ hiểu tốt các concept/alias đã khai báo hoặc suy ra từ Markdown hiện có.
  • Importer không cố parse mọi schema session ngoài Codex. Nó đọc JSONL/log-like records phòng thủ, đủ cho Codex session hiện tại và dễ mở rộng adapter sau.
  • Redaction luôn bật dù máy local. Tradeoff là có thể redact hơi rộng với vài text giống token, nhưng bảo vệ vault khỏi accidental secret capture.
  • Bounded import giúp context --compact không bị treo trên history lớn, nhưng nếu có nhiều session cũ thì các lần context sau sẽ tiếp tục bắt kịp dần.
  • Không scan mọi skill/subagent body và không thêm skill core mới, để bộ kit vẫn xoay quanh Superpowers + 3 quality gates.
