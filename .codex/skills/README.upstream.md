# Upstream Notes

This folder keeps a trimmed, project-portable skill set.

- `superpowers/` is vendored as the primary workflow layer.
- `karpathy-coding-principles/` is the compact coding-principles layer derived
  from the previous Karpathy guideline skill and edited to avoid replacing
  Superpowers workflow guidance.

Specialist skills are intentionally not shipped in this kit. Use repo-local
context, custom subagents, and current documentation lookup for frontend,
backend, database, CI/CD, cloud, security, or framework-specific work.
