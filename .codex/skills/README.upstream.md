# Upstream Notes

This folder keeps a trimmed, project-portable skill set.

- `superpowers/` is vendored as the primary workflow layer.
- `frontend-design/` keeps its upstream license in `LICENSE.txt`.
- `agent-api/` is a local portable skill for model/provider backend work.
- `karpathy-coding-principles/` is the compact coding-principles layer derived
  from the previous Karpathy guideline skill and edited to avoid replacing
  Superpowers workflow guidance.

Removed specialist skills are intentionally not shipped in this kit. Use custom
subagents or current documentation lookup for narrow database, CI/CD, cloud,
security, or framework-specific work.
